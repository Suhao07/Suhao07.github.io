# 本地草稿

这个目录用于仅在本地维护、暂时不参与网站构建的 Markdown 草稿，可以自由建立主题
子目录。

需要注意：

- 本目录不会被 GitHub Pages 构建脚本扫描。
- Pages CMS 不会显示或编辑这里的文件。
- 草稿完成后，将它移动到 `content/posts/`，补齐合法的 YAML frontmatter 后才能
  发布。
- 如果希望在 Pages CMS 中继续编辑草稿，应把文件直接放在 `content/posts/`，并将
  `published` 设置为 `false`。

新草稿可以从 `content/templates/article-template.md` 复制。
